# Параллельное программирование

Решения лабораторных работ курса. Каждая папка содержит исходный код, инструкции и материалы экспериментов.

| Лабораторная | Тема | Папка |
| --- | --- | --- |
| 1 | Последовательное умножение матриц | [lab1](lab1/README.md) |
| 2 | Умножение матриц с OpenMP | [lab2](lab2/README.md) |
| 3 | Умножение матриц с MPI и запуск на «Сергее Королёве» | [lab3](lab3/README.md) |
| 4 | Умножение матриц с CUDA и замеры на Tesla M2070 | [lab4](lab4/README.md) |
| 5 | Параллельная генерация множества Мандельброта, Stanford CS149 | [lab5](lab5/README.md) |

Для Python-скриптов проверки и графиков установите зависимости:

```bash
python3 -m pip install -r requirements.txt
```

Команды сборки и запуска приведены отдельно в README соответствующей лабораторной.
